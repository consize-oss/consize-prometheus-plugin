# Security

Report sensitive vulnerabilities through [GitHub private vulnerability reporting](https://github.com/consize-oss/consize-prometheus-plugin/security/advisories/new). Use public issues for non-sensitive bugs only.

This plugin is experimental. Supported updates target the latest release; fix distribution uses a new version. Trust a reviewed publisher public key before executing plugins. Installation validates signed catalog metadata and artifact digests; activation is explicit. Keep credential files readable only by the Consize runtime identity. Publisher private keys belong in repository Actions secrets and must never be committed.
